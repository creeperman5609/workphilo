Multiverse Nightmares

A Asymetrical Roblox game inspired by previous successors. Made to use unique characters and mechanics to neatly balance out the gameplay style to a unique playstyle for everyone. Including copywrited characters so the game is made for the players and not for the profit. We have sure rules that doesn't change for any of the devs and one of those is profitting off this project. The project is entirely made from the motivation of the team and the feedback of the players. Besides that the game will include a couple game modes off release and progressively add more content to the game, as developers see fit.
